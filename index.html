Avant de commencer

NakT enregistre dans votre compte privé :

  • les dates de début de vos règles et leurs durées ;
  • la durée de vos cycles ;
  • les entrées de votre journal (humeur, symptômes, flux, température) ;
  • les dates de vos tests de grossesse (date seulement, jamais de résultat).

Pourquoi ? Uniquement pour calculer vos prochaines règles, votre ovulation estimée et vos rappels de test. Ces données sont stockées sur Supabase et protégées : personne d'autre que vous ne peut les lire (protection « Row Level Security » de la base de données).

NakT est un outil d'estimation. Il n'est pas une méthode de contraception ni un diagnostic médical.
